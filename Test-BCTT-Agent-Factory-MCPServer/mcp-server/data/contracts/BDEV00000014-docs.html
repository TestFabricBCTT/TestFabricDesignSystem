Deep Dive — Core

Core gere o ciclo de vida completo dos Depósitos a Prazo: criação, reforço, mobilização, renovação, cálculo de juros e penalidades. Emite eventos para notificação de vencimento (30d + no dia). Dados persistidos em tabela term_deposits com campos: id, client_id, account_id, amount, start_date, end_date, interest_rate, term_months, auto_renew, status, penalty_rate.

API REST stateless. Scheduler job (cron) verifica diariamente depósitos próximos do vencimento e emite termDeposit.matured (30d antes + no dia). Cálculo de penalidade: (redeemed_amount * penalty_rate * days_remaining / 365). Renovação automática: job cron renova automaticamente depósitos com auto_renew=true no vencimento.

Lacunas Identificadas

  • Falta integração com sistema de contabilidade (lançamentos de juros)
  • Falta aprovação manual para mobilizações acima de 50.000 EUR
  • Falta rate-limiting por cliente (evitar spam de constituições)

Recomendações

  • Adicionar tabela term_deposits_audit para log de todas as operações (compliance)
  • Adicionar endpoint GET /api/v1/term-deposits/pending-maturity para backoffice
  • Implementar validação de business hours (constituições só em dias úteis)
  • Adicionar campo metadata (JSON) na tabela para extensibilidade futura
