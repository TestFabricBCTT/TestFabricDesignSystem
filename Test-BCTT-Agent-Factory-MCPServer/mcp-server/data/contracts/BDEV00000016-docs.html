Deep Dive — Core

Core backend gere todas as tabelas de crédito habitação (15 tabelas + 2 backoffice), motor de cálculo TAEG (biblioteca financeira standard), mock CRC (score 600-850, delay 3s), sistema interno de avaliação (24-48h), motor de aprovação multinível (L1≤400k, L2 400k-1M, L3>1M), mock CMD (aceita qualquer OTP), integração real Core Banking para desembolso (retry + idempotency), geração FIN/FINE via templates, sistema de notificações multicanal, e módulo de backoffice completo (KPIs, atribuição, notas internas, auditoria, relatórios XLSX).

Modelo de dados normalizado com 15 tabelas core + 2 tabelas backoffice (mortgage_application_assignments, mortgage_internal_notes). Motor de aprovação baseado em state machine (draft→submitted→crc_check→valuation→approval→contract→signed→disbursed→active). Auditoria em tabela audit_logs para compliance. RGPD: soft delete com retenção 2 anos. Desembolso: idempotency key (disbursementId), timeout 30s, circuit breaker. Backoffice: atribuição automática por montante, alertas >5 dias sem acção, exportação XLSX via exceljs.
